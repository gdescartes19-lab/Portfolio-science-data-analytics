CASO 03

De información no estructurada a datos analizables

Proyecto desarrollado en R que combina procesamiento de lenguaje, expresiones regulares, extracción estructurada de información y web scraping. El flujo demuestra cómo transformar texto y contenido web en estructuras de datos que pueden analizarse y visualizarse.

R rvest tm wordcloud stringr ggplot2
Text Mining Limpieza de corpus, matriz término-documento y comparación de vocabulario entre textos.
Scraping Extracción con rvest de 381 registros desde una tabla web de Wikipedia y transformación de variables.
Visualización Comparison cloud, commonality cloud, barras por año y dispersión temporal de reseñas.
Hallazgos y técnicas demostradas Las nubes comparativas permiten distinguir vocabulario característico y compartido entre “La comunidad del anillo” y “Las dos torres”. El scraping convierte tablas HTML en un dataset estructurado y el uso de expresiones regulares extrae nombres, teléfonos, correos, fechas y formatos numéricos desde texto no estructurado.

A través de mis proyectos aplico Python, SQL Server, R, Power BI, DAX y técnicas estadísticas para desarrollar procesos que abarcan desde la preparación y exploración de los datos hasta su análisis, visualización y comunicación.
