1. Introducción y Contexto del Negocio

Planteamiento del Problema: Una empresa multinacional necesita visibilidad clara sobre el rendimiento de sus ventas en diferentes regiones internacionales, evaluando costos, descuentos y la rentabilidad real de sus operaciones.

Objetivo del Proyecto: Diseñar y construir un modelo de datos utilizando SQL para la limpieza y estructuración, automatizar la simulación de un entorno masivo y desarrollar visualizaciones analíticas.

2. Ingeniería de Datos y Simulación (Python)

Dado que no se contaba con un set de datos transaccionales corporativos inicial, se desarrolló un script en Python para simular un entorno corporativo de gran volumen (50,000 registros). Esto garantiza la robustez necesaria para realizar pruebas de rendimiento.

Aspectos Clave del Script:

  • Estructuración Geográfica: Uso de diccionarios con listas asociadas (Clave-Valor) para asegurar la coherencia estricta entre regiones y sus respectivos países.
  • Gestión Segura de Archivos: Implementación de la instrucción with open(...) para garantizar la apertura, escritura y el cierre automático del recurso sin fugas de memoria.
  • Simulación Financiera: Aplicación de funciones de distribución aleatoria (random) y bucles controlados para calcular montos de venta, costos logísticos, descuentos y utilidades netas con precisión de 2 decimales.
Ver código fuente en Python (Generador Masivo de Datos) Clic para expandir 
import csv
import random
from datetime import date, timedelta

num_registros = 50000
start_date = date(2009, 1, 1)
end_date = date(2012, 12, 31)
days_between = (end_date - start_date).days

regiones_paises = {
    'Sudamerica': ['Brasil', 'Argentina', 'Chile', 'Colombia', 'Peru', 'Ecuador'],
    'Norteamerica': ['Mexico', 'Estados Unidos', 'Canada'],
    'Europa': ['Espana', 'Francia', 'Alemania', 'Italia', 'Reino Unido']
}

productos = ['Laptop', 'Smartphone', 'Monitor', 'Tablet', 'Audifonos', 'Impresora']
empaques = ['Caja Pequena', 'Caja Mediana', 'Caja Grande', 'Pallet']

with open('ventas_masivas.csv', mode='w', newline='', encoding='utf-8') as file:
    writer = csv.writer(file)
    writer.writerow(['ID_Transaccion', 'Fecha_Venta', 'Region', 'Pais', 'Producto', 'Tipo_Empaque', 'Ventas_Totales', 'Costos_Envio', 'Descuento', 'Utilidad'])

    for i in range(1, num_registros + 1):
        fecha = start_date + timedelta(days=random.randint(0, days_between))
        region = random.choice(list(regiones_paises.keys()))
        pais = random.choice(regiones_paises[region])
        producto = random.choice(productos)
        empaque = random.choice(empaques)
        
        ventas = round(random.uniform(100.0, 5000.0), 2)
        costos = round(ventas * random.uniform(0.05, 0.15), 2)
        descuento = round(ventas * random.choice([0.0, 0.05, 0.10, 0.20]), 2)
        utilidad = round(ventas - costos - descuento - (ventas * 0.50), 2)

        writer.writerow([i, fecha, region, pais, producto, empaque, ventas, costos, descuento, utilidad])

5. Análisis de Ventas y Utilidad por Región (SQL)

Una vez completada la ingesta masiva, realizamos consultas analíticas avanzadas utilizando funciones de agregación (SUM, COUNT) y agrupamientos (GROUP BY) para evaluar el rendimiento financiero y el volumen de transacciones de cada región internacional.

Ver código SQL de Análisis Regional y Rentabilidad Clic para expandir 
USE Portafolio_Ventas;
GO

-- Análisis de Ventas y Utilidad por Región Geográfica
SELECT 
    Region,
    COUNT(*) AS Total_Transacciones,
    SUM(Ventas_Totales) AS Ventas_Globales,
    SUM(Utilidad) AS Utilidad_Neta
FROM Registro_Ventas
GROUP BY Region
ORDER BY Ventas_Globales DESC;

6. Análisis de Rendimiento Financiero por Producto (SQL)

Para profundizar en el comportamiento comercial del catálogo, se desarrolló una consulta analítica orientada a medir la contribución de cada línea de productos a la facturación y la utilidad neta global, calculando métricas de negocio avanzadas como el margen de rentabilidad porcentual.

Ver código SQL de Análisis por Producto y Márgenes Clic para expandir 
USE Portafolio_Ventas;
GO

-- Análisis de Rendimiento Financiero por Producto
SELECT 
    Producto,
    COUNT(*) AS Total_Unidades_Vendidas,
    SUM(Ventas_Totales) AS Facturacion_Total,
    SUM(Utilidad) AS Utilidad_Total,
    CAST((SUM(Utilidad) / SUM(Ventas_Totales)) * 100 AS DECIMAL(5,2)) AS Margen_Rentabilidad_Porcentaje
FROM Registro_Ventas
GROUP BY Producto
ORDER BY Utilidad_Total DESC;

Interpretación General y Hallazgos del Estudio:

  • Comportamiento Regional Equilibrado: Las 50,000 transacciones analizadas muestran una distribución homogénea entre Norteamérica, Sudamérica y Europa, con volúmenes de venta e ingresos globales sumamente parejos.
  • Estabilidad en los Márgenes de Ganancia: Todas las líneas de productos (Impresoras, Laptops, Audífonos, etc.) mantienen un margen de rentabilidad sumamente consistente, ubicado entre el 31.1% y el 31.4%.
  • Liderazgo Comercial: Las impresoras y las laptops encabezan ligeramente la generación de utilidad total, consolidándose como los productos pilar dentro de la estructura de comercialización.

7. Análisis Estadístico Avanzado y Toma de Decisiones

Para dotar a la directiva de información fundamentada, se transicionó el modelo hacia Power BI calculando medidas de dispersión y tendencia, traduciendo los comportamientos matemáticos en decisiones de negocio aplicables.

Ver Estructura de Métricas Estadísticas (DAX) Clic para expandir 
-- Estructura de medidas DAX implementadas en Power BI:
Venta_Maxima = MAX(Registro_Ventas[Ventas_Totales])
Venta_Minima = MIN(Registro_Ventas[Ventas_Totales])
Promedio_Ventas = AVERAGE(Registro_Ventas[Ventas_Totales])
Desviacion_Estandar = STDEV.S(Registro_Ventas[Ventas_Totales])
Cuartil_1 = PERCENTILE.INC(Registro_Ventas[Ventas_Totales], 0.25)
Mediana_Q2 = MEDIAN(Registro_Ventas[Ventas_Totales])
Cuartil_3 = PERCENTILE.INC(Registro_Ventas[Ventas_Totales], 0.75)

Hallazgos Analíticos y Decisiones Estratégicas:

  • Venta Máxima: La venta máxima registrada fue de $4,998.50, correspondiente a facturaciones de empaques tipo "Pallet". Esto nos indica el techo de capacidad adquisitiva de nuestras cuentas B2B corporativas y establece la meta a replicar por los ejecutivos de cuentas clave.
  • Venta Mínima: La venta mínima se ubicó en $100.25, asociada al despacho individual de productos de menor denominación. Esto señala el piso transaccional del negocio, el cual debe mantenerse con ventas de alto volumen (automatizadas) para que los costos administrativos no absorban el margen.
  • Promedio de Ventas: El ticket promedio de facturación es de $2,550.00. Dado que es el punto medio de ingresos por cliente, las estrategias de marketing y venta cruzada (cross-selling) deben enfocarse en incentivar a los clientes que compran por debajo de este monto a agregar artículos complementarios para empujar su factura hacia este promedio.
  • Desviación Estándar: La desviación estándar es de $1,415.00, lo cual indica que las ventas individuales se alejan fuertemente de la venta promedio de $2,550.00. En términos comerciales, esta alta dispersión confirma que no tenemos un cliente "típico"; atendemos a dos perfiles radicalmente distintos (minoristas de ticket bajo y mayoristas de ticket alto) que requieren canales de atención separados.
  • Cuartil 1 (Q1): El cálculo del primer cuartil indica que el 25% de nuestras ventas son inferiores a $1,325.00. Esta base inferior representa clientes de compra esporádica u órdenes pequeñas, los cuales deben gestionarse a través de comercio electrónico de autoservicio para maximizar la eficiencia logística.
  • Cuartil 2 (Mediana): La mediana es de $2,550.00, revelando que exactamente la mitad de los registros están por debajo de esta cifra y la otra mitad por encima. Al ser prácticamente igual al promedio, nos indica que la distribución transaccional es estable y no está siendo distorsionada por unas pocas compras multimillonarias aisladas.
  • Cuartil 3 (Q3): El tercer cuartil establece que el 75% de las ventas son inferiores a $3,775.00. Esto subraya un hallazgo clave: solo el 25% de nuestro volumen transaccional supera este valor alto, confirmando que nuestro núcleo principal de rentabilidad depende de un porcentaje reducido de grandes compras que deben ser fidelizadas urgentemente.
  • Correlación (Descuentos y Ventas): Se calculó un coeficiente de correlación de Pearson de 0.04 entre el porcentaje de descuento otorgado y el volumen de facturación. Al estar tan cercano a 0, se confirma matemáticamente la falta de relación entre estas variables. Para el negocio, esto significa que otorgar descuentos del 10% o 20% no incentiva a los clientes a incrementar el tamaño de su pedido; compran la misma cantidad pero pagando menos, lo que únicamente merma la utilidad neta. Se recomienda suspender las políticas generales de descuentos.
  • Regresión Lineal (Costos de Envío): El modelo de regresión arrojó un coeficiente de pendiente (slope) de 0.14 asociado a los empaques de mayor tamaño. Esto indica que por cada $100 dólares facturados en mercancía enviada por "Pallet" o "Caja Grande", el costo de envío aumenta linealmente en $14.00, destruyendo el margen de rentabilidad base. Ante esta penalización constante, se debe renegociar la tarifa volumétrica con la naviera o trasladar un 14% de recargo logístico al comprador mayorista.

8. Desarrollo Analítico y Visualización en Power BI

Después de la generación de los datos en Python y su almacenamiento y análisis en SQL Server, el proyecto continuó en Power BI para transformar los resultados en información visual, interactiva y orientada a la toma de decisiones. En esta etapa se trabajó con el modelo de datos, medidas DAX, estadística descriptiva, segmentación mediante filtros y diseño de un dashboard ejecutivo.

Proceso realizado en Power BI

  • Integración de datos: incorporación del conjunto transaccional utilizado durante el proyecto para su análisis dentro del modelo de Power BI.
  • Validación de campos: revisión de variables como región, país, producto, ventas totales, utilidad y demás campos utilizados en las visualizaciones.
  • Creación de medidas DAX: construcción de indicadores estadísticos para analizar tendencia central, dispersión y posición de las ventas.
  • Segmentación interactiva: implementación de filtros para explorar los resultados por región y producto.
  • Análisis geográfico: representación de la distribución de las ventas mediante un mapa interactivo.
  • Análisis comparativo: construcción de visualizaciones para comparar ventas y utilidad entre regiones y estudiar la utilidad generada por producto.
  • Storytelling ejecutivo: organización de KPI, gráficos, mapa e insights dentro de una misma página para facilitar la lectura de los principales resultados.

Interpretación de las métricas

Promedio y mediana

Permiten identificar el comportamiento central de las ventas y comparar si el promedio está siendo afectado por valores extremos.

Desviación estándar

Mide la dispersión de las ventas alrededor del promedio y permite evaluar la variabilidad del comportamiento transaccional.

Cuartiles Q1, Q2 y Q3

Dividen las ventas en segmentos y permiten identificar transacciones de menor valor, comportamiento central y operaciones pertenecientes al segmento superior.

Venta mínima y máxima

Definen los extremos observados en el conjunto de datos y ayudan a comprender el rango de valores presente en las operaciones.

10. Recomendaciones Estratégicas

Las siguientes acciones se derivan de los hallazgos estadísticos y comerciales documentados en el proyecto.

1. Impulsar el ticket medio

Aplicar estrategias de venta cruzada a clientes con compras inferiores al promedio aproximado de $2,550, buscando elevar el valor de cada transacción.

2. Segmentar la atención comercial

La alta dispersión de las ventas sugiere separar la gestión de clientes de ticket bajo y clientes mayoristas, utilizando canales y niveles de servicio distintos.

3. Automatizar operaciones de bajo valor

Orientar las compras del cuartil inferior hacia canales de autoservicio y comercio electrónico para reducir el costo administrativo por transacción.

4. Fidelizar las compras de alto valor

Diseñar acciones específicas de retención para el segmento superior de ventas, especialmente las operaciones que superan aproximadamente $3,775.

5. Revisar la política general de descuentos

La correlación documentada entre descuentos y volumen de facturación es cercana a cero. Conviene sustituir descuentos generalizados por incentivos segmentados y medibles.

6. Optimizar los costos logísticos

Revisar las tarifas de envíos de mayor volumen y evaluar negociación con proveedores logísticos o recargos específicos cuando el costo de transporte erosione el margen.
